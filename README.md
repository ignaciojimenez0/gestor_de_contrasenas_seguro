### Descripción
Gestor de contraseñas seguro con autenticación PKI y cifrado híbrido. Tecnologías: Python, HTML. Herramientas criptográficas: SHA-256, RSA 2048-bit, AES-256-CTR, HMAC-SHA256, certificados X.509 vía OpenSSL

### Instrucciones de uso
1. Instalar dependencias con `pip install -r requirements.txt`
2. Ejecutar la aplicación con `python3 backend/main.py`
3. Ir a `http://localhost:5500` en un navegador para usar la aplicación
